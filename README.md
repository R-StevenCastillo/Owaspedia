# Owaspedia

## Descripción de la Aplicación
Es una aplicación web educativa que está diseñada para ofrecer una experiencia de aprendizaje optimizada mediante una interfaz intuitiva y atractiva. La aplicación, construida con las tecnologías de Node.js, Express.js, JavaScript, HTML y CSS, permite la gestión de usuarios mediante un sistema CRUD, lo que facilita la creación, lectura, actualización y eliminación de registros de forma eficiente.
